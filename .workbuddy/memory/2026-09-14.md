### 技术踩坑（重要，下次直接复用）
1. **WebBridge 守护进程被 shell 回收**：PS 工具每次调用后 shell 销毁，`Start-Process` / `nohup` / 后台任务启动的 daemon 都会被连带杀掉（表现为「PID 文件存在但 HTTP 探测失败」+ `os error 10061`）。**解决方案：注册 Windows 计划任务**（`Register-ScheduledTask` + `Start-ScheduledTask`），daemon 在独立会话中常驻，实测稳定。
2. **残留 PID 文件必须先删**：daemon 死后 `~/.kimi-webbridge/daemon.pid` 残留会让 `status` 一直报 stuck，启动前先确认 PID 进程已死并删除该文件。
3. **版本不匹配可忽略**：daemon v1.11.3 + 扩展 v2.0.9 + skill v1.11.3，`status` 报警但 `navigate/evaluate` 实际可用，无需升级即可跑通。
4. **config.json 必须无 BOM**（run.ps1 读取）；`.ps1` 脚本必须 UTF-8 BOM。用 Write 工具写 config.json 会带上 BOM，需用 `[System.IO.File]::WriteAllText($p,$c,[System.Text.UTF8Encoding]::new($false))` 去 BOM。
5. **PS 工具 stdout 捕获异常**：脚本实际执行成功但 stdout 为空、exit code 异常（如 exit 1）。**必须以写入临时文件再 Read 的方式取回输出**，不要以「无输出」判定失败。
6. **Bash 工具在本机不可用**（PortableGit 缺 dirname/ls/cat 等），全部改用 PowerShell。
