### 根因分析（两个 bug）

**Bug 1：姓名收集阶段误判"已到底"**
- 原实现用 CDP `mouseWheel` 在固定坐标 (500,600) 滚动，对虚拟滚动列表不可靠。
- 停滞阈值 `$stag -ge 3` 过于激进，在第 11 次滚动就判定到底，实际列表有 **142 个唯一姓名**。
- **修复**：改为 JS 直接滚容器 `document.querySelector('.app-layout--default').scrollTop += 900`；停滞阈值提高到 **12 轮**；并加 `$maxScrolls = 80` 硬上限防死循环。

**Bug 2：下载阶段从底部开始"往下找"，永远找不到**
- 收集阶段把列表滚到了底部；下载阶段**未重置回顶部**，且查找循环只往下滚（`DeltaY 600`），已在底部无法再下滚 → 15 次重试原地打转。
- **修复**：① 收集完姓名后、进入下载前执行 `scrollTop = 0` 归零；② 每个候选人的查找循环**第 0 轮先归零到顶部**再逐屏下滑；③ 重试上限 15 → **25 次**。

**修复后验证**：姓名收集 139 个；原先 `[SKIP]` 的 吴先生/陈先生/高先生 全部成功下载；全程 **0 失败 0 跳过**。

### 第二轮（续）：真正根因推翻前案 + 最终跑通

> ⚠️ **重要订正**：#41 / #42 的「详情页在新标签页」判断**是误判**。真正根因是 **#44：标签页被遮挡**。

**#44 ★★★ 真正根因：标签页被遮挡 → Chrome 不投递输入事件**

daemon 原始报错（决定性证据）：
```
the click did not reach the page — no pointerdown/mousedown fired.
The tab is likely backgrounded and occluded (another tab in its window is shown,
so its render widget is hidden and real input isn't delivered).
```
- 同窗口多标签页时，非前台标签页的 render widget 被隐藏，**Chrome 不向它投递任何真实输入事件** → 所有 `Input.dispatchMouseEvent` / `mouse_click` **静默失败**（返回 `ok:true` 但页面毫无反应）。
- 修复：新增 `Ensure-TabFocused`（调 CDP `Page.bringToFront`）+ `Invoke-Click`（WebBridge `click` action，DOM 级派发）。**每次交互前都调 `Ensure-TabFocused`**。
- **结论订正**：智联详情面板是**当前标签页内的 `.resume-detail-wrap`**，不需要切标签页。`Switch-ToDetailTab` / `Clear-StaleDetailTabs` / `Test-OnDetailTab` 方案**全部废弃**。

**#45 存至本地按钮延迟挂载 10~15 秒**
- 面板主体 `.resume-detail-wrap`（约 1107×715）先渲染，`.resume-button.position-r` 要等简历正文加载完才挂载。
- 原等待上限 15×500ms=7.5s 远远不够 → 探测失败 → 退回硬编码坐标 → 点了个不存在的按钮 → `No save dialog` → 空转。
- 修复：**两段式等待** —— 先等 `.resume-detail-wrap`（20×500ms），再等按钮可见（**40×750ms ≈ 30 秒**）。

**#46 ★★★ 最终跑通的关键：按钮会"闪烁"，必须"探测到即刻点击"**
- `.resume-button.position-r` 反复挂载/卸载（Vue 渲染过程），探测到"存在"不代表点击那一刻还在。
- 正确序列（4 步，缺一不可）：
  1. CDP `Page.bringToFront`（不置前输入被丢弃）
  2. DOM `click .talent-basic-info__name` 打开面板（面板在当前标签页内渲染）
  3. **探测到按钮可见的那一瞬间立即发 CDP 鼠标序列**（moved → pressed → 80ms → released），**中间不加任何等待**，否则按钮已卸载
  4. 用 `getBoundingClientRect()` 实时坐标，**不要用配置兜底值**；探不到时先判断面板是否还在，收了就重开
- **分工铁律**：**候选人姓名用 DOM click，面板内按钮（存至本地/word/保存）必须用 CDP 真实鼠标事件**，二者不可混用（Vue 组件不响应程序化 `.click()`）。
- 重试次数：3.4 阶段 4 次 → **12 次**。
